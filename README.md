# Lockin

Мобильный клиент Lockin для Android: поиск матчей, ready-check, чат и создание лобби Mobile Legends.

## Установка

1. Скачайте `lockin.apk` из раздела [Releases](../../releases).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника, разрешите.
3. Для создания лобби приложение запросит разрешение «Подключение VPN».

Требуется Android 7.0 (API 24) или новее.
